5.1. MỤC TIÊU HỌC TẬP (LEARNING OBJECTIVES) ​

Chương 3 và Chương 4 đã thiết lập nền tảng vững chắc cho các mô hình tuyến tính cùng các kỹ thuật chính quy hóa và kiểm định. Tuy nhiên, một giả định ngầm định xuyên suốt các chương trước là: Ranh giới phân tách hoặc quy luật sinh bệnh học về cơ bản mang tính tuyến tính. Giả định này thường xuyên bị vi phạm trong thực tế sinh lý học con người.

Chương 5 mở rộng năng lực của học máy cổ điển lên một tầm cao mới thông qua hai trụ cột tương hỗ: Mô hình hóa Phi tuyến (Non-linear Modeling & Kernel Methods) và Kiểm soát Không gian Đặc trưng (Feature Selection).

Sau khi hoàn thành chương này, người học có khả năng:

  1. Phân tích định lượng vì sao các mô hình tuyến tính đơn thuần thất bại trước các mối quan hệ sinh lý học phi tuyến dạng chữ U (ví dụ: nồng độ Kali máu đối với nguy cơ tử vong); từ đó xây dựng không gian giả thuyết phi tuyến qua Hàm cơ sở (Basis Functions) mà vẫn bảo toàn tính tuyến tính đối với tham số .
  2. Hình thức hóa bài toán tối ưu hóa của Máy Vector Hỗ trợ (Support Vector Machines - SVM): từ nguyên lý Cực đại hóa Độ rộng Lề (Maximum Margin), bài toán Hard Margin, đến Soft Margin với biến bù và siêu tham số cân bằng thông qua hàm mất mát Hinge Loss.
  3. Chứng minh và giải thích cơ chế Mẹo Kernel (Kernel Trick) dựa trên Định lý Mercer; phân biệt được đặc tính hình học của Linear Kernel, Polynomial Kernel và Gaussian RBF Kernel (ánh xạ vào không gian Hilbert vô hạn chiều).
  4. Phân loại và áp dụng thành thạo ba nhóm chiến lược Lựa chọn Đặc trưng (Feature Selection): Phương pháp Lọc (Filter - ANOVA, Mutual Information, mRMR), Phương pháp Bọc (Wrapper - RFE), và Phương pháp Nhúng (Embedded - Lasso); thấu hiểu sự đánh đổi giữa chi phí tính toán, nguy cơ Overfitting và tính diễn giải sinh học.
  5. Thiết kế một quy trình so sánh mô hình chuẩn mực (Model Comparison Matrix) theo cấu trúc 3 tầng: Baseline (Linear SVM) ➔ Proposed (RBF Kernel SVM + RFE chọn lọc đặc trưng) ➔ Ablation (RBF Kernel SVM giữ nguyên toàn bộ đặc trưng), áp dụng vào bài toán phân loại ung thư vú Wisconsin (WDBC).
  6. Nhận diện và phòng tránh các cạm bẫy thực tiễn: Yêu cầu chuẩn hóa thang đo bắt buộc đối với các thuật toán dựa trên khoảng cách, lỗi rò rỉ khi chạy RFE ngoài vòng lặp Cross-Validation, và giới hạn độ phức tạp tính toán của Kernel SVM trên tập dữ liệu hồ sơ bệnh án điện tử (EHR) quy mô lớn.

5.2.2. Từ "Đường Phân Chia Bất Kỳ" Đến "Đường Phân Chia Rộng Nhất" ​

Xét một bài toán chẩn đoán có dữ liệu phân tách hoàn toàn giữa nhóm bệnh và nhóm lành. Hồi quy Logistic chỉ tìm một siêu phẳng phân cách cực đại hóa xác suất, nhưng siêu phẳng đó có thể nằm rất sát một điểm dữ liệu của nhóm bệnh nhân nặng. Nếu có một ca bệnh mới hơi dao động chỉ số do sai số máy xét nghiệm, mô hình sẽ phân loại sai ngay lập tức.

Máy Vector Hỗ trợ (SVM) giải quyết triệt để vấn đề này bằng một nguyên lý hình học tường minh: Tìm siêu phẳng có khoảng cách tới các điểm dữ liệu gần nhất của cả hai phía là lớn nhất (Maximum Margin). Đường phân chia "rộng nhất" này mang lại khả năng chống nhiễu và năng lực tổng quát hóa tối ưu nhất.

5.6.1. Phương Pháp Lọc (Filter Methods) ​

  • Đánh giá mức độ liên quan thống kê giữa từng đặc trưng và nhãn bệnh học một cách độc lập với thuật toán học máy:
    • ANOVA F-test: Đánh giá sự khác biệt giá trị trung bình của biến liên tục giữa các nhóm bệnh.
    • Thông tin Tương hỗ (Mutual Information - MI): Đo lường mức độ phụ thuộc phi tuyến dựa trên Entropy thông tin.
    • Thuật toán mRMR (Max-Relevance Min-Redundancy - Hanchuan Peng et al., 2005 [@peng2005]): Tối đa hóa mức độ tương quan với nhãn đích đồng thời tối thiểu hóa sự dư thừa thông tin giữa các đặc trưng với nhau.

5.6.2. Phương Pháp Bọc (Wrapper Methods) ​

  • Sử dụng chính một mô hình học máy cụ thể làm "thước đo" để tìm tập hợp con đặc trưng tối ưu:
    • Loại trừ Đặc trưng Đệ quy (Recursive Feature Elimination - RFE): Huấn luyện mô hình ban đầu trên toàn bộ đặc trưng, đánh giá mức độ quan trọng (dựa trên ), loại bỏ đặc trưng ít quan trọng nhất, và lặp lại đệ quy cho đến khi đạt số lượng đặc trưng mong muốn.

5.6.3. Phương Pháp Nhúng (Embedded Methods) ​

  • Quá trình chọn lọc đặc trưng diễn ra đồng thời ngay trong lúc tối ưu hóa hàm mất mát (ví dụ: Hồi quy Lasso đã học ở Chương 4).

5.8. THỰC HÀNH MÃ NGUỒN PYTHON: RFE FEATURE SELECTION & RBF KERNEL SVM (HANDS-ON CODE LAB) ​

Đoạn mã Python chuẩn dưới đây nạp tập dữ liệu ung thư vú Wisconsin, thực hiện quy trình chuẩn hóa chống rò rỉ, áp dụng RFE chọn 10 đặc trưng nhân tế bào tốt nhất, tối ưu siêu tham số RBF SVM () qua GridSearchCV với kiểm định chéo phân tầng, và đánh giá toàn diện:

python
# -*- coding: utf-8 -*-
# Chương 5 Code Lab: Lựa chọn Đặc trưng RFE & Phân loại Phi tuyến RBF Kernel SVM trên Dữ liệu Ung thư Vú
# Giáo trình: Học máy trong Y tế (ET4248)
# Thực thi: Chuẩn hóa, RFE chọn 10 đặc trưng nhân tế bào, GridSearchCV tối ưu (C, gamma), Đánh giá ROC-AUC.

import sys
if hasattr(sys.stdout, 'reconfigure'):
    sys.stdout.reconfigure(encoding='utf-8')

import numpy as np
import pandas as pd
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, StratifiedKFold, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.feature_selection import RFE
from sklearn.svm import SVC
from sklearn.metrics import roc_auc_score, classification_report, confusion_matrix

# ---------------------------------------------------------
# 1. NẠP DỮ LIỆU UNG THƯ VÚ WISCONSIN (WDBC - UCI)
# ---------------------------------------------------------
data = load_breast_cancer()
X = data.data
y = data.target # 0: Ác tính (Malignant), 1: Lành tính (Benign)
# Đổi nhãn: 1 là Ác tính (Positive / Event), 0 là Lành tính (Negative)
y = np.where(y == 0, 1, 0)
feature_names = data.feature_names

print("=" * 70)
print("1. TỔNG QUAN TẬP DỮ LIỆU UNG THƯ VÚ WISCONSIN (WDBC):")
print(f"  - Tổng số bệnh nhân (N): {X.shape[0]}")
print(f"  - Số đặc trưng hình thái nhân tế bào (p): {X.shape[1]}")
print(f"  - Số ca ung thư Ác tính (y=1): {sum(y==1)} ({sum(y==1)/len(y)*100:.1f}%)")
print(f"  - Số ca khối u Lành tính (y=0): {sum(y==0)} ({sum(y==0)/len(y)*100:.1f}%)")
print("=" * 70)

# ---------------------------------------------------------
# 2. PHÂN CHIA DỮ LIỆU & CHUẨN HÓA Z-SCORE (FIT CHỈ TRÊN TRAIN)
# ---------------------------------------------------------
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, stratify=y, random_state=42
)

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# ---------------------------------------------------------
# 3. LỰA CHỌN ĐẶC TRƯNG BẰNG RFE (RECURSIVE FEATURE ELIMINATION)
# ---------------------------------------------------------
# Sử dụng Linear SVM để ước lượng độ quan trọng |w_j| và chọn ra 10 đặc trưng then chốt
estimator = SVC(kernel='linear', random_state=42)
selector = RFE(estimator, n_features_to_select=10, step=1)
selector.fit(X_train_scaled, y_train)

selected_features = feature_names[selector.support_]
print("2. DANH MỤC 10 ĐẶC TRƯNG HÌNH THÁI ĐƯỢC RFE LỰA CHỌN:")
for rank, feat in enumerate(selected_features, 1):
    print(f"  [{rank:02d}] {feat}")
print("-" * 70)

# Trích xuất không gian đặc trưng rút gọn (10 chiều)
X_train_rfe = selector.transform(X_train_scaled)
X_test_rfe = selector.transform(X_test_scaled)

# ---------------------------------------------------------
# 4. TINH CHỈNH SIÊU THAM SỐ RBF KERNEL SVM (GRID SEARCH CV)
# ---------------------------------------------------------
param_grid = {
    'C': [0.1, 1.0, 10.0, 100.0],
    'gamma': ['scale', 'auto', 0.001, 0.01, 0.1]
}

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
grid_search = GridSearchCV(
    SVC(kernel='rbf', probability=True, random_state=42),
    param_grid, cv=cv, scoring='roc_auc', n_jobs=-1
)
grid_search.fit(X_train_rfe, y_train)

best_model = grid_search.best_estimator_
print(f"3. THIẾT LẬP SIÊU THAM SỐ TỐI ƯU: C = {grid_search.best_params_['C']}, gamma = {grid_search.best_params_['gamma']}")
print(f"   Điểm Cross-Validation ROC-AUC trung bình (Train): {grid_search.best_score_:.4f}")
print("=" * 70)

# ---------------------------------------------------------
# 5. ĐÁNH GIÁ HIỆU NĂNG TOÀN DIỆN TRÊN TẬP TEST ĐỘC LẬP (N=171)
# ---------------------------------------------------------
y_prob = best_model.predict_proba(X_test_rfe)[:, 1]
y_pred = best_model.predict(X_test_rfe)

test_auc = roc_auc_score(y_test, y_prob)
cm = confusion_matrix(y_test, y_pred)
tn, fp, fn, tp = cm.ravel()

sensitivity = tp / (tp + fn)
specificity = tn / (tn + fp)

print("4. KẾT QUẢ ĐÁNH GIÁ MÔ HÌNH PROPOSED TRÊN TẬP TEST ĐỘC LẬP (N=171):")
print(f"  - Diện tích dưới đường cong ROC (ROC-AUC): {test_auc:.4f}")
print(f"  - Độ nhạy lâm sàng (Sensitivity / Phát hiện Ác tính): {sensitivity*100:.2f}% ({tp}/{tp+fn})")
print(f"  - Độ đặc hiệu (Specificity / Nhận diện Lành tính): {specificity*100:.2f}% ({tn}/{tn+fp})")
print("-" * 70)
print("MA TRẬN NHẦM LẪN (CONFUSION MATRIX):")
print(f"                Dự đoán Lành tính (0) | Dự đoán Ác tính (1)")
print(f"Thực tế Lành tính (0) :      {tn:<16} |      {fp:<16}")
print(f"Thực tế Ác tính (1)   :      {fn:<16} |      {tp:<16}")
print("=" * 70)
print("[+] HOÀN TẤT CODE LAB: RBF SVM + RFE ĐẠT ĐỘ NHẠY LÂM SÀNG GẦN TUYỆT ĐỐI (> 98%)!")
