Topic 1.1: Predicting Acute Decompensated Heart Failure / Readmission Risk ​

Topic group: 1. Biomedical Signals & Time-series · Status: ✅ Starter literature complete · ⏳ Detailed workflow/timeline follows the common template

📥 Full documentation on GitHub

Raw data and detailed source code are kept Private on the department's GitHub repository (so students complete the work themselves). This page gives you the essential information to get started.

Read the Management Framework & Rubric first — this page only specifies the details for the heart-failure problem.

1. Problem statement ​

Research questionPredict the risk of acute decompensated heart failure (ADHF) or 30-day readmission from vital-sign time series or EHR data using machine learning
Input (X)Tabular clinical features (age, EF, eGFR, serum potassium, history...) or continuous vital-sign time series (heart rate via wearable)
Output (Y)Binary: readmission/death within a defined time window (30 days, or 21-day early warning)
PopulationHeart failure patients (HFpEF/HFrEF), elderly, possibly with comorbidities (T2DM)
Suggested datasetMIMIC-III/IV (cardiovascular patient time series extracted), or simulated data based on a public registry
Specific challengeIrregular sampling frequency in clinical time series; early warning (24-48h ahead) has higher clinical value than late detection

vanes2025circadian202510.1002/ehf2.15395Genuine LSTM on time series of circadian heart rate (wearable), N=65, AUC~0.74, predicting ADHF 21 days ahead

Lesson from zhai2026explaina

AUC drops sharply from 0.968 (internal) to 0.718 (external validation on eICU-CRD) — concrete evidence of overfitting risk when only evaluating internally. Teams choosing this topic must design external validation if possible, or at minimum clearly discuss this limitation when they cannot.

PRISMA diagram ​

3. Workflow & Timeline ​

Follow the common 7-stage workflow and 15-week timeline (see the full template on Topic 1.2 — Arrhythmia). Heart-failure-specific technical notes:

  • gd3-preprocessing: if using tabular/EHR data — handle missing values with MICE/KNN Imputer fit only on Train; if using vital-sign time series — normalize windowing, handle irregular sampling. Patient-level split is mandatory by patient ID (never let one patient appear in both Train and Test).
  • gd4/gd5: a mandatory Logistic Regression baseline (as maesecalvo2026predicti did) before trying RF/XGBoost/LSTM.
  • gd6-evaluation-xai: use SHAP for tabular models (as wang2025machine, zhai2026explaina did); if choosing the LSTM route, consider attention weights or time-series SHAP for explainability.
  • Extension suggestion: if the team has time, try combining tabular features + time series (multimodal) — this is a gap none of the 4 starter papers have explored.

4. Open items (from the literature report) ​

  1. comparator/validation_strategy of vanes2025circadian needs the full text to complete.
  2. Students must add ≥6 more papers to meet the ≥10-paper requirement of Rubric Milestone 1.
