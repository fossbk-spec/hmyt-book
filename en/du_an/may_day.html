Topic 2.1: Segmenting and Measuring Wheals from Skin Photos to Support Urticaria Management ​

Topic group: 2. Medical Imaging (Fundus/Dermatology) · Status: ⚠️ Small-scale literature (6 trial records) — needs expansion before formal use

📥 Full documentation on GitHub

Raw data and detailed source code are kept Private on the department's GitHub repository (so students complete the work themselves). This page gives you the essential information to get started.

Read the Management Framework & Rubric first.

1. Problem statement ​

Research questionSegment and measure the area/severity of wheals from skin photographs to support Urticaria severity assessment
Input (X)Photo of the affected skin area, ideally with a size-reference object (ruler/color card)
Output (Y)A wheal segmentation mask + area converted to cm², or a severity score (Urticaria Activity Score)
Suggested datasetSelf-collected with a reference object, or open-source dermoscopy datasets
Specific challengeHairy skin, lighting noise; converting pixels to real-world size (cm) for an accurate wheal area score

2. Starter literature (1 INCLUDE + 3 CONTEXT + 2 EXCLUDE) ​

Direct-literature-scarce topic

Only 1 direct precedent was found for the computer-vision problem on urticaria — and it is itself hive counting/detection rather than pixel-level segmentation (Dice/IoU) as the research question asks. This is a sign of a genuine research gap — good as an opening argument (Introduction) for the team's report, but it also means the team will struggle to find ≥10 directly relevant papers and needs to broaden the search to other dermatology conditions using similar methods (skin-lesion area measurement in general).

INCLUDE record ​

maccarthy2024auas — Automatic Urticaria Activity Score: Deep Learning-Based Automatic Hive Counting for Urticaria Severity Assessment, JID Innovations 2024 (doi: 10.1016/j.xjidi.2023.100218). Legit.Health-UAS-HiveNet model, 313 images labeled by 5 experts, Krippendorff alpha = 0.826 (hive counting) / 0.603 (severity grading).

Lesson on literal vs. spirit of inclusion criteria

This paper is a counting/detection problem reporting Krippendorff alpha (inter-rater agreement) — not Dice/IoU as the inclusion criteria literally state. It was kept because it satisfies the broader outcome axis ("Severity correlation") and is the closest evidence available. Lesson for students: when a paper nearly matches but doesn't 100% match the criteria's wording, don't unilaterally include or exclude it — document the conflict and let the committee/instructor decide.

3. Workflow & Timeline ​

Follow the common 7-stage workflow / 15-week timeline (see the detailed template at Topic 1.2 — Arrhythmia). Specific notes:

  • gd1-proposal: because direct literature is scarce, the team needs to spend more time here broadening the search (dermoscopy in general, skin-lesion area measurement via CV) rather than only searching the exact keyword "urticaria".
  • gd2-dataset-eda: if self-collecting images, a size-reference object must be in every frame from the start (cannot be added later).
  • gd3-preprocessing: normalize lighting/color, handle hair/fur noise, augmentation suited to realistic capture-angle variation.
  • gd6-evaluation-xai: use Grad-CAM/U-Net segmentation maps as visual XAI evidence; cross-check automatic scores against expert assessment (as maccarthy2024auas did with Krippendorff alpha).
