5.1. LEARNING OBJECTIVES ​

Chapters 3 and 4 built a solid foundation of linear models together with regularization and validation techniques. However, an implicit assumption ran through those chapters: that the separating boundary or the underlying disease mechanism is fundamentally linear. This assumption is frequently violated in real human physiology.

Chapter 5 extends the power of classical machine learning to a new level through two complementary pillars: Non-linear Modeling & Kernel Methods and Controlling the Feature Space (Feature Selection).

Upon completing this chapter, learners will be able to:

  1. Quantitatively analyze why purely linear models fail on U-shaped non-linear physiological relationships (e.g., serum potassium versus mortality risk); and from there build a non-linear hypothesis space via Basis Functions that remains linear in the parameters .
  2. Formalize the optimization problem of Support Vector Machines (SVM): from the Maximum-Margin principle, through the Hard Margin problem, to the Soft Margin with slack variables and the trade-off hyperparameter via the Hinge Loss function.
  3. Derive and explain the Kernel Trick mechanism based on Mercer's Theorem; distinguish the geometric properties of the Linear Kernel, Polynomial Kernel and Gaussian RBF Kernel (mapping into an infinite-dimensional Hilbert space).
  4. Classify and confidently apply three groups of Feature Selection strategies: Filter Methods (ANOVA, Mutual Information, mRMR), Wrapper Methods (RFE), and Embedded Methods (Lasso); understand the trade-off between computational cost, Overfitting risk, and biological interpretability.
  5. Design a rigorous model comparison pipeline (Model Comparison Matrix) using a three-tier structure: Baseline (Linear SVM) ➔ Proposed (RBF Kernel SVM + RFE feature selection) ➔ Ablation (RBF Kernel SVM keeping all features), applied to the Wisconsin breast-cancer (WDBC) classification problem.
  6. Recognize and avoid practical pitfalls: the mandatory scaling requirement for distance-based algorithms, the leakage error of running RFE outside the Cross-Validation loop, and the computational limit of Kernel SVM on large-scale electronic health record (EHR) datasets.

5.2. CLINICAL MOTIVATION: NON-LINEAR BIOLOGICAL LAWS & THE MAXIMUM-MARGIN PRINCIPLE (CLINICAL MOTIVATION) ​

5.2.2. From "Any Separating Line" to "The Widest Separating Line" ​

Consider a diagnostic problem whose data is perfectly separable between the diseased and healthy groups. Logistic Regression only finds a separating hyperplane that maximizes probability, but that hyperplane may sit very close to a data point from the severely ill group. If a new case has a slightly different value due to lab measurement error, the model will misclassify it immediately.

Support Vector Machines (SVM) resolve this decisively through an explicit geometric principle: find the hyperplane whose distance to the nearest data points on both sides is largest (Maximum Margin). This "widest" separating line provides the best noise robustness and generalization ability.

5.6.1. Filter Methods ​

  • Evaluate the statistical relevance of each feature to the disease label independently of the machine-learning algorithm:
    • ANOVA F-test: assesses the difference in mean values of a continuous variable across disease groups.
    • Mutual Information (MI): measures the degree of non-linear dependence based on information entropy.
    • mRMR (Max-Relevance Min-Redundancy — Hanchuan Peng et al., 2005 [@peng2005]): maximizes relevance to the target label while simultaneously minimizing redundancy among the features themselves.

5.6.2. Wrapper Methods ​

  • Use a specific machine-learning model itself as the "yardstick" to find the optimal feature subset:
    • Recursive Feature Elimination (RFE): trains an initial model on all features, ranks importance (based on ), removes the least important feature, and repeats recursively until the desired number of features is reached.

5.6.3. Embedded Methods ​

  • Feature selection happens simultaneously while optimizing the loss function (e.g., Lasso Regression learned in Chapter 4).

5.8. HANDS-ON PYTHON CODE LAB: RFE FEATURE SELECTION & RBF KERNEL SVM (HANDS-ON CODE LAB) ​

The standard Python script below loads the Wisconsin breast-cancer dataset, applies a leakage-safe scaling procedure, uses RFE to select the 10 best cell-nucleus features, tunes the RBF SVM hyperparameters () via GridSearchCV with stratified cross-validation, and performs a comprehensive evaluation:

python
# -*- coding: utf-8 -*-
# Chapter 5 Code Lab: RFE Feature Selection & Non-linear RBF Kernel SVM Classification on Breast Cancer Data
# Course: Machine Learning in Healthcare (ET4248)
# Demonstrates: scaling, RFE selecting 10 nuclear features, GridSearchCV tuning (C, gamma), ROC-AUC evaluation.

import sys
if hasattr(sys.stdout, 'reconfigure'):
    sys.stdout.reconfigure(encoding='utf-8')

import numpy as np
import pandas as pd
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, StratifiedKFold, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.feature_selection import RFE
from sklearn.svm import SVC
from sklearn.metrics import roc_auc_score, classification_report, confusion_matrix

# ---------------------------------------------------------
# 1. LOAD THE WISCONSIN BREAST CANCER DATASET (WDBC - UCI)
# ---------------------------------------------------------
data = load_breast_cancer()
X = data.data
y = data.target # 0: Malignant, 1: Benign
# Relabel: 1 = Malignant (Positive / Event), 0 = Benign (Negative)
y = np.where(y == 0, 1, 0)
feature_names = data.feature_names

print("=" * 70)
print("1. WISCONSIN BREAST CANCER DATASET (WDBC) OVERVIEW:")
print(f"  - Total patients (N): {X.shape[0]}")
print(f"  - Number of cell-nucleus morphology features (p): {X.shape[1]}")
print(f"  - Number of malignant cases (y=1): {sum(y==1)} ({sum(y==1)/len(y)*100:.1f}%)")
print(f"  - Number of benign cases (y=0): {sum(y==0)} ({sum(y==0)/len(y)*100:.1f}%)")
print("=" * 70)

# ---------------------------------------------------------
# 2. SPLIT THE DATA & Z-SCORE STANDARDIZATION (FIT ONLY ON TRAIN)
# ---------------------------------------------------------
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, stratify=y, random_state=42
)

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# ---------------------------------------------------------
# 3. FEATURE SELECTION VIA RFE (RECURSIVE FEATURE ELIMINATION)
# ---------------------------------------------------------
# Use a Linear SVM to estimate importance |w_j| and select the 10 key features
estimator = SVC(kernel='linear', random_state=42)
selector = RFE(estimator, n_features_to_select=10, step=1)
selector.fit(X_train_scaled, y_train)

selected_features = feature_names[selector.support_]
print("2. THE 10 MORPHOLOGY FEATURES SELECTED BY RFE:")
for rank, feat in enumerate(selected_features, 1):
    print(f"  [{rank:02d}] {feat}")
print("-" * 70)

# Extract the reduced (10-dimensional) feature space
X_train_rfe = selector.transform(X_train_scaled)
X_test_rfe = selector.transform(X_test_scaled)

# ---------------------------------------------------------
# 4. TUNE THE RBF KERNEL SVM HYPERPARAMETERS (GRID SEARCH CV)
# ---------------------------------------------------------
param_grid = {
    'C': [0.1, 1.0, 10.0, 100.0],
    'gamma': ['scale', 'auto', 0.001, 0.01, 0.1]
}

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
grid_search = GridSearchCV(
    SVC(kernel='rbf', probability=True, random_state=42),
    param_grid, cv=cv, scoring='roc_auc', n_jobs=-1
)
grid_search.fit(X_train_rfe, y_train)

best_model = grid_search.best_estimator_
print(f"3. OPTIMAL HYPERPARAMETER SETTING: C = {grid_search.best_params_['C']}, gamma = {grid_search.best_params_['gamma']}")
print(f"   Mean Cross-Validation ROC-AUC (Train): {grid_search.best_score_:.4f}")
print("=" * 70)

# ---------------------------------------------------------
# 5. FULL PERFORMANCE EVALUATION ON THE INDEPENDENT TEST SET (N=171)
# ---------------------------------------------------------
y_prob = best_model.predict_proba(X_test_rfe)[:, 1]
y_pred = best_model.predict(X_test_rfe)

test_auc = roc_auc_score(y_test, y_prob)
cm = confusion_matrix(y_test, y_pred)
tn, fp, fn, tp = cm.ravel()

sensitivity = tp / (tp + fn)
specificity = tn / (tn + fp)

print("4. PROPOSED-MODEL EVALUATION RESULTS ON THE INDEPENDENT TEST SET (N=171):")
print(f"  - Area under the ROC curve (ROC-AUC): {test_auc:.4f}")
print(f"  - Clinical sensitivity (malignant detection): {sensitivity*100:.2f}% ({tp}/{tp+fn})")
print(f"  - Specificity (benign identification): {specificity*100:.2f}% ({tn}/{tn+fp})")
print("-" * 70)
print("CONFUSION MATRIX:")
print(f"                Predicted Benign (0) | Predicted Malignant (1)")
print(f"Actual Benign (0)    :      {tn:<16} |      {fp:<16}")
print(f"Actual Malignant (1) :      {fn:<16} |      {tp:<16}")
print("=" * 70)
print("[+] CODE LAB COMPLETE: RBF SVM + RFE ACHIEVES NEAR-PERFECT CLINICAL SENSITIVITY (> 98%)!")

5.9. REAL-WORLD PITFALLS, ETHICS & COMPUTATIONAL CONSTRAINTS (PITFALLS & CONSTRAINTS) ​

5.9.1. Mandatory Scaling for Distance-Based SVM ​

The RBF Kernel function depends directly on Euclidean distance. If a variable with a large scale (e.g., tumor area in , values ) is combined with a variable on a small scale (e.g., nuclear smoothness, values ), the area variable will completely dominate the computed distance, turning the algorithm into an effectively univariate classifier.

  • Mandatory rule: always standardize with StandardScaler before feeding data into SVM.

5.9.2. The Leakage Pitfall of Running RFE Outside the Cross-Validation Loop ​

Similar to the warning in Chapter 4, if RFE is run on the entire dataset to select 10 features before performing Cross-Validation, the Test set's label information leaks into the variable-selection step, producing an artificial ROC-AUC.

  • Remedy: always integrate RFE inside a scikit-learn Pipeline or use RFECV.

5.9.3. The Computational Limit of Kernel SVM on Large Datasets ​

The quadratic-programming solver used by Kernel SVM (e.g., the SMO algorithm) requires computing and storing an Kernel matrix, with time complexity ranging from to . When working with a national electronic-health-record database with patients, Kernel SVM becomes infeasible in memory and computation; one must then switch to an approximate Linear SVM via the Nyström method, or to a deep neural network.

5.11. OPEN RESEARCH CHALLENGES (OPEN RESEARCH CHALLENGES) ​

5.11.1. Sparse Support Vector Machines (-Norm SVM / Sparse SVM) ​

On smart wearable medical devices (IoMT) with limited compute and battery, storing thousands of Support Vectors from a Kernel SVM is infeasible. The -Norm SVM research direction replaces the norm with the norm on the weights and coefficients , both optimizing the margin and eliminating of the Support Vectors, allowing an embedded microcontroller to perform real-time inference in just a few microseconds.

5.11.2. Quantum Support Vector Machines (QSVM) ​

For massive biomedical datasets, computing the Kernel matrix takes days on a classical supercomputer. Quantum SVM (QSVM) uses a -dimensional quantum Hilbert state space to compute the Kernel dot product in logarithmic time , opening a new era for whole-genome sequencing analysis at million-person scale.

5.11.3. A Direction Awaiting Data: SVM on Brain MRI for Dementia Diagnosis ​

A classic SVM application in biomedicine is classifying Alzheimer's vs. Normal Cognition from structural MRI features (hippocampal volume, MTA/Scheltens atrophy score) combined with an RBF or Linear Kernel on features extracted by a CNN (see Chapter 8). The international benchmark datasets for this problem are ADNI (Alzheimer's Disease Neuroimaging Initiative) and OASIS-3, both of which require a Data Use Agreement before access — unlike WDBC in §5.7, this is not yet a case study that can be run directly in this course; it is presented here to orient learners toward the reference datasets they should seek out when pursuing real research on dementia imaging diagnosis.

Golden Rules for Applying SVM & Feature Selection: ​

  1. Always scale before running SVM: margin optimization and the RBF Kernel function are completely distorted if features have mismatched scales.
  2. Choose the Kernel that matches the nature of the data: use a Linear Kernel when (gene data); use a Gaussian RBF Kernel when is moderate and biological boundaries have local non-linearity.
  3. Never run Feature Selection outside the CV loop: every variable-filtering algorithm (RFE, mRMR) must sit inside each fold to prevent Selection Leakage.
  4. Balance complexity with interpretability: an RBF SVM combined with 10 features selected by RFE often carries higher clinical value than a model keeping 100 redundant features.
