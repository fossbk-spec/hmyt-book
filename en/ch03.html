3.2. CLINICAL MOTIVATION & THE LINEAR-MODEL PARADOX (CLINICAL MOTIVATION) ​

3.2.1. The Linear Model Paradox: "Low Representational Power" yet the "Clinical Gold Standard" ​

Judged purely on mathematical representational capacity, the linear model is one of the simplest model families. It can only draw a flat separating hyperplane in the feature space, and is entirely powerless against complex nonlinear patterns.

And yet, in Evidence-Based Medicine (EBM), Logistic Regression remains the most enduring "workhorse" of the past half-century, and is always the mandatory Baseline model in every clinical trial and international medical-AI publication.

The root cause lies in three factors that are vital to the healthcare setting:

  1. Intrinsic Interpretability: A cardiologist cannot accept a "black-box" model that outputs an probability of myocardial infarction without a reason. With Logistic Regression, the physician knows exactly: "For every increase in systolic blood pressure, the odds of heart disease increase by a factor of ()".
  2. Clinical Auditability: The coefficients let a physician cross-check the model directly against pathophysiology. If the model assigns a negative weight to a known risk factor (e.g., labeling smoking as reducing cancer risk due to a confounder), the physician can immediately detect and reject the model.
  3. Every Classic Clinical Risk Score is Built on Logistic Regression: Most of the famous scores in modern medicine — from the Framingham Cardiovascular Score, the Stroke Score, to the APACHE II Critical Care Score — are, mathematically, all Logistic Regression models converted into a cumulative integer point score.

3.5. LOGISTIC REGRESSION FOR BINARY MEDICAL CLASSIFICATION (LOGISTIC REGRESSION) ​

3.5.1. Why Does Linear Regression Fail at Binary Classification? ​

When solving a disease classification problem (e.g., is Cancer, is Healthy), using pure Linear Regression runs into two fatal limitations:

  1. Meaningless Probability Predictions: The linear function has a range spanning the entire real number line , leading to meaningless output probabilities such as or .
  2. The Decision Boundary is Shifted by Outliers: The MSE loss penalizes the squared distance. If the dataset contains one "extremely typical" patient with a very high test value, deep in the positive region, the linear regression line will be "pulled" toward that outlier, shifting the classification boundary at the threshold and causing a batch of patients near the boundary to be misclassified.

3.9. PYTHON HANDS-ON LAB: TRAINING LOGISTIC REGRESSION & EXTRACTING THE ODDS RATIO (HANDS-ON CODE LAB) ​

The standard Python code below is completely self-running, simulating a 500-patient cardiovascular risk dataset, training a Logistic Regression model, computing clinical evaluation metrics, and automatically extracting an Odds Ratio coefficient table with confidence intervals:

python
# -*- coding: utf-8 -*-
# Chapter 3 Code Lab: Training Logistic Regression & Extracting a Clinical Odds Ratio Table
# Course: Machine Learning in Healthcare (ET4248)
# Demonstrates: Scaling, Training, ROC-AUC Evaluation, and Computing OR with 95% CI.

import sys
if hasattr(sys.stdout, 'reconfigure'):
    sys.stdout.reconfigure(encoding='utf-8')

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score, brier_score_loss, classification_report, confusion_matrix

# ---------------------------------------------------------
# 1. SIMULATED CARDIOVASCULAR RISK DATASET (N=500 PATIENTS)
# ---------------------------------------------------------
np.random.seed(42)
n_samples = 500

# Clinical features
age = np.random.normal(loc=55, scale=10, size=n_samples).clip(30, 80)
sbp = np.random.normal(loc=130, scale=18, size=n_samples).clip(90, 200)  # systolic blood pressure
chol = np.random.normal(loc=210, scale=35, size=n_samples).clip(120, 320)  # Cholesterol (mg/dL)
smoking = np.random.binomial(1, p=0.35, size=n_samples)  # 1: Smoker, 0: Non-smoker
diabetes = np.random.binomial(1, p=0.20, size=n_samples)  # 1: Diabetic, 0: Non-diabetic

# Model the disease probability via a realistic Logit function
# logit = -8.5 + 0.06*age + 0.025*sbp + 0.012*chol + 0.85*smoking + 1.10*diabetes
z_true = -8.5 + 0.06*age + 0.025*sbp + 0.012*chol + 0.85*smoking + 1.10*diabetes
prob_true = 1 / (1 + np.exp(-z_true))
y = np.random.binomial(1, prob_true, size=n_samples)

df = pd.DataFrame({
    'patient_id': [f"PT_{i:03d}" for i in range(n_samples)],
    'age': age,
    'sbp': sbp,
    'cholesterol': chol,
    'smoking': smoking,
    'diabetes': diabetes,
    'cvd_event': y
})

print("=" * 70)
print("1. CARDIOVASCULAR RISK DATASET OVERVIEW (FRAMINGHAM CVD COHORT):")
print(df.head())
print(f"Event distribution: No event = {sum(y==0)} ({sum(y==0)/n_samples*100:.1f}%), CVD event = {sum(y==1)} ({sum(y==1)/n_samples*100:.1f}%)")
print("=" * 70)

# ---------------------------------------------------------
# 2. SPLITTING & PREPROCESSING (FIT ON TRAIN ONLY)
# ---------------------------------------------------------
feature_names = ['age', 'sbp', 'cholesterol', 'smoking', 'diabetes']
X = df[feature_names].values
y = df['cvd_event'].values

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, stratify=y, random_state=42
)

# Scale continuous variables (fit on train)
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# ---------------------------------------------------------
# 3. TRAINING THE LOGISTIC REGRESSION MODEL
# ---------------------------------------------------------
# C = 1e5 to approximate an unpenalized Logistic Regression
model = LogisticRegression(C=1e5, solver='lbfgs', random_state=42)
model.fit(X_train_scaled, y_train)

# ---------------------------------------------------------
# 4. EVALUATING PERFORMANCE ON THE INDEPENDENT TEST SET (N=150)
# ---------------------------------------------------------
y_pred = model.predict(X_test_scaled)
y_prob = model.predict_proba(X_test_scaled)[:, 1]

roc_auc = roc_auc_score(y_test, y_prob)
brier = brier_score_loss(y_test, y_prob)

print("2. MODEL EVALUATION RESULTS ON THE TEST SET (N=150):")
print(f"  - Area under the ROC curve (ROC-AUC): {roc_auc:.4f}")
print(f"  - Brier calibration score (lower is better): {brier:.4f}")
print("-" * 70)
print("DETAILED CLASSIFICATION REPORT:")
print(classification_report(y_test, y_pred, target_names=['No event', 'CVD event']))

# ---------------------------------------------------------
# 5. EXTRACTING & COMPUTING THE CLINICAL ODDS RATIO TABLE WITH 95% CI
# ---------------------------------------------------------
# Train on the original (unscaled) scale so the coefficients carry direct clinical meaning
model_raw = LogisticRegression(C=1e5, solver='lbfgs', max_iter=1000, random_state=42)
model_raw.fit(X_train, y_train)

# Estimate the covariance matrix via a Fisher Information approximation
p_pred_train = model_raw.predict_proba(X_train)[:, 1]
W_diag = p_pred_train * (1 - p_pred_train)
X_design = np.hstack([np.ones((X_train.shape[0], 1)), X_train])
V = np.diag(W_diag)
cov_matrix = np.linalg.inv(X_design.T @ V @ X_design)
se_weights = np.sqrt(np.diag(cov_matrix))[1:]  # skip the intercept

weights = model_raw.coef_[0]
odds_ratios = np.exp(weights)
ci_lower = np.exp(weights - 1.96 * se_weights)
ci_upper = np.exp(weights + 1.96 * se_weights)

or_summary_df = pd.DataFrame({
    'Clinical Factor': feature_names,
    'Coefficient (w)': weights.round(4),
    'Standard Error (SE)': se_weights.round(4),
    'Odds Ratio (OR)': odds_ratios.round(4),
    '95% CI Lower': ci_lower.round(4),
    '95% CI Upper': ci_upper.round(4)
})

print("=" * 70)
print("3. CLINICAL ODDS RATIO SUMMARY TABLE:")
print(or_summary_df.to_string(index=False))
print("=" * 70)
print("[+] PIPELINE RAN PERFECTLY: MEETS EVIDENCE-BASED MEDICINE (EBM) INTERPRETATION STANDARDS!")

3.10. REAL-WORLD PITFALLS, ASSUMPTIONS & CLINICAL CONSTRAINTS (PITFALLS & CONSTRAINTS) ​

3.10.1. Multicollinearity ​

In medical data, many test indices measure the same underlying physiological process (e.g., Hemoglobin and Hematocrit , or the liver enzymes and ). When two variables have too high a linear correlation ():

  • The matrix becomes nearly singular, causing the standard error to be dramatically inflated.
  • The sign of a weight can flip in an absurd way (e.g., a risk variable is assigned a negative weight).
  • Detection & Remedy: Assess the Variance Inflation Factor (VIF):If (or ), one of the variables must be dropped, or Ridge / Lasso Regularized Regression must be applied (covered in Chapter 4).

3.10.2. The Linearity Assumption vs. Nonlinear Biological Relationships (U-Shaped Curves) ​

Logistic Regression assumes the Log-Odds varies linearly with the independent variable. However, many real biological patterns are U-shaped or J-shaped nonlinear:

  • Body Mass Index (BMI) vs. Mortality Rate: Both severely underweight people () and severely obese people () have a high mortality rate, while people with a normal () have the lowest risk.
  • If is entered into the model linearly, the algorithm will ignore the risk of the underweight group.
  • Remedy: Clinical binning (Categorization), or using polynomial basis functions (Restricted Cubic Splines).

3.10.3. The Pitfall of Mistaking Correlation for Causation ​

An () coefficient only proves a Statistical Association, not a biological causal relationship. Uncontrolled Confounders can create spurious correlations that lead to erroneous intervention decisions.

Core Takeaways to Remember: ​

  1. The linear combination is the foundation of every machine-learning model: every deep neural network or complex classifier is built from layers of linear combinations combined with nonlinear activation functions.
  2. Never use linear regression for classification: always use a Sigmoid/Softmax link function to ensure the output is a valid probability distribution on .
